**yarr** (yet another rss reader) is a web-based feed aggregator which can be used both
as a desktop application and a personal self-hosted server.

The app is a single binary with an embedded database (SQLite).

## Features

* Runs as a desktop app (with tray icon) or a self-hosted server
* Single static binary, no runtime dependencies
* Embedded SQLite database, no external DB server required
* Web UI that works in any modern browser
* [Fever API](https://github.com/nkanaev/yarr) support for third-party clients
