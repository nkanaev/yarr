*yarr* (yet another rss reader) は Web ベースのフィードアグリゲーターです。

{{< img src="promo.png" alt="yarr プロモ" >}}

## 特徴

ほぼどこでも動作する軽量なアプリ。

- クロスプラットフォーム: Windows、macOS、Linux
- 依存関係のない単一バイナリ
- デスクトップアプリまたはセルフホストサーバー
- デスクトップ、タブレット、モバイルに対応したレスポンシブ Web UI
- ホーム画面の Web アプリ (PWA) としてインストール可能
- SQLite または PostgreSQL ストレージ

落ち着いたデザイン。快適な操作性。

- テーマ: ライト、ベージュ、ナイト、システム自動
- 全記事を対象とした全文検索
- 最小限の設定、極めて少ないリソース使用量
- 素早いナビゲーションのためのキーボードショートカット
- ローカルでの快適な閲覧を実現する Readability エンジン
- 添付ファイル対応 - リーダー内でのポッドキャスト、動画、YouTube の再生

ストレスのないフィード管理。

- フィード形式: Atom、RSS、RDF、JSON
- OPML のインポート/エクスポート
- バックグラウンドでのフィード定期更新
- サードパーティ製モバイルアプリ向けの Fever 互換 API
- スクリプトや自動化のための REST API

プライバシーに配慮した設計。特別な手間をかけずに安全を確保。

- リモートアクセス用の Basic 認証
- カスタム TLS 証明書による HTTPS
- クロスサイトトラッキングを防ぐ厳格な Referrer ポリシー
- 安全に閲覧するためのコンテンツサニタイズ（浄化）
