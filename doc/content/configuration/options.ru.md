Сервер принимает опции в виде аргументов командной строки и/или переменных окружения.
Флаг командной строки имеет приоритет над переменной окружения.

| Флаг         | Переменная окружения | Описание                                                                |
| ------------ | -------------------- | ----------------------------------------------------------------------- |
| `-addr`      | `YARR_ADDR`          | Адрес, на котором работает сервер (по умолчанию `127.0.0.1:7070`)     |
| `-base`      | `YARR_BASE`          | Базовый путь URL сервиса                                                |
| `-auth`      | `YARR_AUTH`          | Пользователь и пароль в формате `username:password`                     |
| `-auth-file` | `YARR_AUTHFILE`      | Путь к файлу с `username:password`. Имеет приоритет над `-auth`         |
| `-cert-file` | `YARR_CERTFILE`      | Путь к файлу сертификата TLS                                            |
| `-key-file`  | `YARR_KEYFILE`       | Путь к файлу ключа TLS                                                  |
| `-db`        | `YARR_DB`            | Путь к файлу хранилища                                                  |
| `-log-file`  | `YARR_LOGFILE`       | Путь к файлу журнала                                                    |
| `-open`      | —                    | Открыть сервер в браузере                                               |

## HTTPS

Для включения HTTPS требуются оба параметра: `-cert-file` и `-key-file`.
