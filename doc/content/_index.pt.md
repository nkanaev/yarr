O *yarr* (yet another rss reader) é um agregador de feeds baseado na web.

{{< img src="promo.png" alt="promocional do yarr" >}}

## Funcionalidades

Uma aplicação pequena que funciona em praticamente qualquer lugar.

- Multiplataforma: Windows, macOS e Linux
- Binário único sem dependências
- Aplicação desktop ou servidor alojado pelo próprio
- Interface web responsiva para desktop, tablet e telemóvel
- Instalável como aplicação web no ecrã principal (PWA)
- Armazenamento em SQLite ou PostgreSQL

Aspeto sóbrio. Confortável de utilizar.

- Temas: Claro, Bege, Noite e Automático do Sistema
- Pesquisa de texto integral em todos os artigos
- Definições mínimas, pegada de recursos mínima
- Atalhos de teclado para uma navegação rápida
- Motor de modo de leitura (Readability) para leitura local
- Suporte para anexos - reprodução de podcasts, vídeo e YouTube no leitor

Gestão de feeds simples e sem complicações.

- Formatos de feed: Atom, RSS, RDF e JSON
- Importação e exportação de OPML
- Agendador de atualizações de feed em segundo plano
- API compatível com Fever para aplicações móveis de terceiros
- API REST para scripts e automação

Privado por conceção. Seguro sem esforço adicional.

- Autenticação básica (Basic Auth) para acesso remoto
- HTTPS com certificados TLS personalizados
- Políticas estritas de Referrer para prevenir rastreio entre sites
- Sanitização de conteúdos para uma leitura segura
