*yarr* (yet another rss reader) es un agregador de feeds basado en la web.

{{< img src="promo.png" alt="yarr promo" >}}

## Características

Una pequeña aplicación que funciona en casi cualquier lugar.

- Multiplataforma: Windows, macOS y Linux
- Binario único sin dependencias
- Aplicación de escritorio o servidor autoalojado
- Interfaz web adaptable para escritorio, tableta y móvil
- Instalable como aplicación web en la pantalla de inicio (PWA)
- Almacenamiento en SQLite o PostgreSQL

Diseño sobrio. Cómodo de usar.

- Temas: Claro, Beige, Noche y Automático del sistema
- Búsqueda de texto completo en todos los artículos
- Configuración mínima, uso mínimo de recursos
- Atajos de teclado para una navegación rápida
- Motor de modo lectura (Readability) para lectura local
- Soporte para adjuntos: reproducción de podcasts, vídeo y YouTube en el lector

Gestión de feeds sin complicaciones.

- Formatos de feed: Atom, RSS, RDF y JSON
- Importación/exportación de OPML
- Programador de actualización de feeds en segundo plano
- API compatible con Fever para aplicaciones móviles de terceros
- API REST para automatización y scripts

Privado por diseño. Seguro sin esfuerzo adicional.

- Autenticación básica (Basic Auth) para acceso remoto
- HTTPS con certificados TLS personalizados
- Políticas estritas de Referrer para evitar el rastreo entre sitios
- Desinfección (sanitización) del contenido para una lectura segura
