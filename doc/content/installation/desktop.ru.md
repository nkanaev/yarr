## Скачивание

Скачайте десктопное приложение со [страницы релизов](https://github.com/nkanaev/yarr/releases/latest). Выберите файл для вашей операционной системы и архитектуры процессора.

| ОС | Архитектура | Скачать |
|---|---|---|
| macOS | Apple Silicon | [yarr_darwin_arm64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_darwin_arm64_gui.zip) |
| macOS | Intel | [yarr_darwin_amd64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_darwin_amd64_gui.zip) |
| Windows | ARM64 | [yarr_windows_arm64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_windows_arm64_gui.zip) |
| Windows | x86-64 | [yarr_windows_amd64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_windows_amd64_gui.zip) |

## macOS

1. Переместите `yarr.app` в папку «Программы».
2. Откройте `yarr.app`.
3. Нажмите на иконку якоря в строке меню.
4. Нажмите **Открыть**.

## Windows

1. Запустите `yarr.exe`.
2. Нажмите на иконку якоря в системном трее.
3. Нажмите **Открыть**.

## Хранение данных

yarr автоматически сохраняет данные в пользовательской папке конфигурации. Ручная настройка не требуется.
