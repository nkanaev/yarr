## Download

Transfira a aplicação desktop a partir da [página de lançamentos](https://github.com/nkanaev/yarr/releases/latest). Selecione o ficheiro para o seu sistema operativo e arquitetura de processador.

| Sistema Operativo | Arquitetura | Transferência |
|---|---|---|
| macOS | Apple Silicon | [yarr_darwin_arm64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_darwin_arm64_gui.zip) |
| macOS | Intel | [yarr_darwin_amd64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_darwin_amd64_gui.zip) |
| Windows | ARM64 | [yarr_windows_arm64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_windows_arm64_gui.zip) |
| Windows | x86-64 | [yarr_windows_amd64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_windows_amd64_gui.zip) |

## macOS

1. Mova o `yarr.app` para a pasta Aplicações.
2. Abra o `yarr.app`.
3. Clique no ícone de âncora na barra de menus.
4. Clique em **Abrir**.

## Windows

1. Execute o `yarr.exe`.
2. Clique no ícone de âncora na área de notificação (tray).
3. Clique em **Abrir**.

## Armazenamento de Dados

O yarr guarda os seus dados automaticamente na pasta de configuração do utilizador. Não é necessária configuração manual.
