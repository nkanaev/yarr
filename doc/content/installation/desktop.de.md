## Download

Laden Sie die Desktop-Anwendung von der [Release-Seite](https://github.com/nkanaev/yarr/releases/latest) herunter. Wählen Sie die passende Datei für Ihr Betriebssystem und Ihre CPU-Architektur aus.

| Betriebssystem | Architektur | Download |
|---|---|---|
| macOS | Apple Silicon | [yarr_darwin_arm64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_darwin_arm64_gui.zip) |
| macOS | Intel | [yarr_darwin_amd64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_darwin_amd64_gui.zip) |
| Windows | ARM64 | [yarr_windows_arm64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_windows_arm64_gui.zip) |
| Windows | x86-64 | [yarr_windows_amd64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_windows_amd64_gui.zip) |

## macOS

1. Verschieben Sie `yarr.app` in den Ordner „Programme“.
2. Öffnen Sie `yarr.app`.
3. Klicken Sie auf das Anker-Symbol in der Menüleiste.
4. Klicken Sie auf **Open**.

## Windows

1. Führen Sie `yarr.exe` aus.
2. Klicken Sie auf das Anker-Symbol im System-Tray.
3. Klicken Sie auf **Open**.

## Datenspeicherung

yarr speichert Ihre Daten automatisch im Konfigurationsordner des Benutzers. Es ist keine manuelle Einrichtung erforderlich.
