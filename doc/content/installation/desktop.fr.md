## Téléchargement

Téléchargez l'application de bureau depuis la [page des versions (releases)](https://github.com/nkanaev/yarr/releases/latest). Sélectionnez le fichier correspondant à votre système d'exploitation et à l'architecture de votre processeur.

| Système d'exploitation | Architecture | Téléchargement |
|---|---|---|
| macOS | Apple Silicon | [yarr_darwin_arm64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_darwin_arm64_gui.zip) |
| macOS | Intel | [yarr_darwin_amd64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_darwin_amd64_gui.zip) |
| Windows | ARM64 | [yarr_windows_arm64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_windows_arm64_gui.zip) |
| Windows | x86-64 | [yarr_windows_amd64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_windows_amd64_gui.zip) |

## macOS

1. Déplacez `yarr.app` dans le dossier Applications.
2. Ouvrez `yarr.app`.
3. Cliquez sur l'icône d'ancre dans la barre des menus.
4. Cliquez sur **Open**.

## Windows

1. Exécutez `yarr.exe`.
2. Cliquez sur l'icône d'ancre dans la zone de notification (system tray).
3. Cliquez sur **Open**.

## Stockage des données

yarr enregistre automatiquement vos données dans le dossier de configuration de l'utilisateur. Aucune configuration manuelle n'est requise.
