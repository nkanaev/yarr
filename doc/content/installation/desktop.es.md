## Descarga

Descarga la aplicación de escritorio desde la [página de lanzamientos](https://github.com/nkanaev/yarr/releases/latest). Selecciona el archivo adecuado para tu sistema operativo y arquitectura de procesador.

| Sistema operativo | Arquitectura | Descarga |
|---|---|---|
| macOS | Apple Silicon | [yarr_darwin_arm64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_darwin_arm64_gui.zip) |
| macOS | Intel | [yarr_darwin_amd64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_darwin_amd64_gui.zip) |
| Windows | ARM64 | [yarr_windows_arm64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_windows_arm64_gui.zip) |
| Windows | x86-64 | [yarr_windows_amd64_gui.zip](https://github.com/nkanaev/yarr/releases/latest/download/yarr_windows_amd64_gui.zip) |

## macOS

1. Mueve `yarr.app` a la carpeta Aplicaciones.
2. Abre `yarr.app`.
3. Haz clic en el icono de ancla en la barra de menús.
4. Haz clic en **Open**.

## Windows

1. Ejecuta `yarr.exe`.
2. Haz clic en el icono de ancla en la bandeja del sistema.
3. Haz clic en **Open**.

## Almacenamiento de datos

yarr guarda tus datos automáticamente en la carpeta de configuración del usuario. No se requiere configuración manual.
