*yarr* (yet another rss reader) — веб-агрегатор RSS-лент.

{{< img src="promo.png" alt="yarr promo" >}}

## Возможности

Одно небольшое приложение, которое работает практически везде.

- Кроссплатформенность: Windows, macOS и Linux
- Один бинарный файл без зависимостей
- Десктопное приложение или собственный сервер
- Адаптивный веб-интерфейс для компьютера, планшета и смартфона
- Установка как PWA (веб-приложение) на главный экран
- Хранение данных в SQLite или PostgreSQL

Лаконичный интерфейс. Удобство использования.

- Темы: светлая, бежевая, тёмная и системная
- Полнотекстовый поиск по всем статьям
- Минимум настроек, минимальное потребление ресурсов
- Горячие клавиши для быстрой навигации
- Встроенный режим чтения (Readability)
- Поддержка медиавложений: воспроизведение подкастов, видео и YouTube прямо в ридере

Удобное управление подписками.

- Форматы лент: Atom, RSS, RDF и JSON
- Импорт/экспорт OPML
- Фоновый планировщик обновления лент
- Fever-совместимый API для сторонних мобильных приложений
- REST API для скриптов и автоматизации

Конфиденциальность по умолчанию. Безопасность из коробки.

- Basic-авторизация (пароль) для удалённого доступа
- HTTPS с собственными TLS-сертификатами
- Строгая политика Referrer для защиты от межсайтового отслеживания
- Фильтрация (санитизация) содержимого для безопасного чтения
