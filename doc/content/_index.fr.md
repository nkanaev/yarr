*yarr* (yet another rss reader) est un agrégateur de flux basé sur le web.

{{< img src="promo.png" alt="yarr promo" >}}

## Fonctionnalités

Une petite application qui fonctionne presque partout.

- Multiplateforme : Windows, macOS et Linux
- Binaire unique sans dépendances
- Application de bureau ou serveur auto-hébergé
- Interface web réactive pour ordinateur, tablette et mobile
- Installable en tant qu'application web sur l'écran d'accueil (PWA)
- Stockage SQLite ou PostgreSQL

Épuré visuellement. Confortable à utiliser.

- Thèmes : Clair, Beige, Nuit et Automatique du système
- Recherche en texte intégral dans tous les articles
- Paramètres minimaux, empreinte mémoire minimale
- Raccourcis clavier pour une navigation rapide
- Moteur de lecture (Readability) pour une lecture locale optimale
- Prise en charge des pièces jointes : lecture de podcasts, vidéos et YouTube dans le lecteur

Gestion de flux sans contrainte.

- Formats de flux : Atom, RSS, RDF et JSON
- Import/Export OPML
- Planificateur de mise à jour des flux en arrière-plan
- API compatible Fever pour applications mobiles tierces
- API REST pour scripts et automatisation

Privé par conception. Sécurisé sans effort supplémentaire.

- Authentification de base (Basic Auth) pour l'accès distant
- HTTPS avec certificats TLS personnalisés
- Politiques strictes sur l'en-tête Referrer pour empêcher le traçage intersite
- Assainissement du contenu pour une lecture en toute sécurité
