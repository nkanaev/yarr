*yarr* (yet another rss reader) is a web-based feed aggregator.

{{< img src="promo.png" alt="yarr promo" >}}

## Features

One small app that runs almost anywhere.

- Cross-platform: Windows, macOS and Linux
- Single binary with zero dependencies
- Desktop app or self-hosted server
- Responsive web UI for desktop, tablet and mobile
- Installable as a home-screen web app (PWA)
- SQLite or Postgres storage

Quiet to look at. Comfortable to use.

- Themes: Light, Beige, Night and System Auto
- Full-text search across all articles
- Minimal settings, minimal footprint
- Keyboard shortcuts for fast navigation
- Readability engine for local reading experience
- Enclosure support - podcasts, video and YouTube playback in the reader

Hassle-free feed management.

- Feed formats: Atom, RSS, RDF and JSON
- OPML import/export
- Background feed scheduler
- Fever-compatible API for third-party mobile apps
- REST API for scripting and automation

Private by design. Secure without extra work.

- Basic auth for remote access
- HTTPS with custom TLS certificates
- Strict Referrer Policies to prevent cross-site tracking
- Content sanitization for safe reading.
