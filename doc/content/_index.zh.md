*yarr*（yet another rss reader）是一个基于 Web 的 Feed 聚合器。

{{< img src="promo.png" alt="yarr 宣传图" >}}

## 功能特性

一款几乎可以在任何地方运行的小巧应用。

- 跨平台：Windows、macOS 和 Linux
- 无依赖项的单二进制文件
- 桌面应用或自托管服务器
- 适用于桌面、平板和手机的响应式 Web 界面
- 可作为主屏幕 Web 应用 (PWA) 安装
- 支持 SQLite 或 PostgreSQL 存储

简洁美观。舒适易用。

- 主题：浅色、米色、夜间和跟随系统
- 全文搜索所有文章
- 最少的设置，极小的资源占用
- 用于快速导航的快捷键
- 用于本地阅读体验的 Readability 引擎
- 支持附件：在阅读器中直接播放播客、视频和 YouTube

轻松管理 Feed。

- Feed 格式：Atom、RSS、RDF 和 JSON
- OPML 导入/导出
- 后台 Feed 定时更新
- 兼容 Fever API，支持第三方移动应用
- 用于脚本和自动化的 REST API

设计即注重隐私。无需额外工作即可实现安全。

- 远程访问的 Basic Auth 认证
- 支持自定义 TLS 证书的 HTTPS
- 严格的 Referrer 策略以防止跨站追踪
- 内容净化以实现安全阅读
