*yarr* (yet another rss reader) ist ein webbasierter Feed-Aggregator.

{{< img src="promo.png" alt="yarr Vorschau" >}}

## Funktionen

Eine kleine Anwendung, die fast überall läuft.

- Plattformübergreifend: Windows, macOS und Linux
- Einzelne Binärdatei ohne Abhängigkeiten
- Desktop-App oder selbstgehosteter Server
- Responsive Web-Benutzeroberfläche für Desktop, Tablet und Smartphone
- Als Web-App auf dem Startbildschirm installierbar (PWA)
- SQLite- oder PostgreSQL-Speicher

Schlichtes Design. Angenehm zu bedienen.

- Themes: Hell, Beige, Nacht und System-Auto
- Volltextsuche über alle Artikel
- Minimale Einstellungen, minimaler Ressourcenverbrauch
- Tastaturkürzel für schnelle Navigation
- Leseansicht-Engine (Readability) für ungestörtes Lesen
- Anhang-Unterstützung – Wiedergabe von Podcasts, Videos und YouTube direkt im Reader

Mühelose Feed-Verwaltung.

- Feed-Formate: Atom, RSS, RDF und JSON
- OPML-Import/Export
- Hintergrund-Feedscheduler
- Fever-kompatible API für mobile Drittanbieter-Apps
- REST-API für Skripte und Automatisierung

Integrierter Datenschutz. Sicher ohne Zusatzaufwand.

- Basic Auth für den Fernzugriff
- HTTPS mit benutzerdefinierten TLS-Zertifikaten
- Strikte Referrer-Richtlinien zur Verhinderung von websiteübergreifendem Tracking
- Inhaltssäuberung (Sanitization) für sicheres Lesen
