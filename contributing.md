Contributions to *yarr* are welcome.

The project values simplicity and substance over style:

- simple codebase
  - little tooling
  - few dependencies
  - few abstractions
- content-first UI:
  - as little [chrome][ui-chrome] as possible
  - fast response to user interaction
  - animations only to draw attention or aid navigation
  - few settings, only when they help focus on content
  - dense, aligned, structured UI and content

Spotted a bug, or have a measurable performance improvement idea? File an [issue
ticket][issue-tickets]. Want to fix it yourself? Pull requests are welcome without
an issue ticket.

Changing the UI? Open a [discussion][discussions] first: brief description,
screenshots if possible, and why it helps other users.

For security issues, email nkanaev@live.com.

Don't know where to start? You can help out with:

- suggesting or proofreading localisations
- validating the Fever API
- improving accessibility
- hardening Docker images
- expanding documentation

AI usage policy: use responsibly, verify, disclose.

Thanks.
